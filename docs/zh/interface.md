# 界面详解

窗口由顶栏、状态栏和三列面板组成。

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 可执行文件 [路径] 选择… 用内置GoTree 重新反射 │ 预设工作流 │ 语言 │ 主题 │
├──────────────────────────── 状态栏 ────────────────────────────────────────┤
│ 命令表        │  输入                      │  工作流                        │
│ （搜索 + 树） │  参数                      │  等价命令行 / 结果              │
└───────────────┴────────────────────────────┴────────────────────────────────┘
```

## 顶栏

| 控件 | 作用 |
|---|---|
| **可执行文件** | 当前驱动哪个命令行工具。可以直接编辑：输入完整路径后回车或点到别处，面板就会反射该二进制。 |
| **选择…** | 用原生文件选择器挑同一个东西。 |
| **用内置 GoTree** | 解出（或复用）编译进主程序的 GoTree 并反射它。首次启动自动走的就是这条路。 |
| **重新反射命令表** | 忽略缓存，重读每一条 `--help`。替换过命令行工具的二进制后用这个。 |
| **预设工作流** | 由工具包提供的按钮，每个把工作流填成一条现成的链条；鼠标悬停可看一行说明。 |
| **语言** | 中文 / English，立即生效并记忆。 |
| **主题** | 跟随系统 / 浅色 / 深色，连 Windows 标题栏一起变。 |

## 状态栏

只有一行反馈，用底色区分严重程度：

| 外观 | 含义 |
|---|---|
| 浅底灰字 | 信息：进度、反射结果、成功。 |
| 琥珀色 | 警告：什么都没执行，例如没选可执行文件、工作流为空、预设引用了当前版本没有的命令。 |
| 红色 | 失败：后端拒绝执行，或某一步报错。消息里会带原因。 |

常见文案：`正在反射命令表…`、`找不到可执行文件：C:\…`、`完成 · 2 步 · 118 ms`、
`1/2 步失败 · <工具自己的消息>`、`已保存到 <路径>`。

## 第一列：命令表

一个搜索框，加上反射出来的命令树，按命令组归类并字母排序。

- **点击叶子节点**即把该命令追加到工作流。
- **虚线边框 + `可执行` 徽标**表示这是一个*双重*命令：它自己可以运行，同时还有子命令
  （GoTree 的 `cut`、`resolve`、`stats`、`prune` 等）。点组标题添加命令本身，点子项添加子命令。
- **命令名后面的灰色文字**是该命令自己的简短说明，取自 `--help`。它保持英文，因为那是命令行的
  文案而不是面板的文案。
- **搜索**同时匹配命令 id 和说明，并保留父级分组，好让你看清命中项在哪。

GoTree 0.5.2 的覆盖情况：35 个命令组、82 个可执行命令、213 个命令私有参数。

## 第二列：输入与参数

**输入**提供两种互斥模式：

- **树文件（传 --input）** —— 一个路径。若工作流第一步带有 `input` 角色的参数且你留空，
  面板会自动填入该路径。
- **直接粘贴** —— 一段 Newick 文本，写进第一个进程的标准输入。

**参数**为当前选中的工作流步骤渲染表单。标题会带上命令名，例如 `参数 · draw svg`。

每个参数一行，包含：

| 部分 | 示例 | 说明 |
|---|---|---|
| 参数名 | `-H, --height` | 长短名按命令行的声明原样呈现。 |
| 类型标记 | `int` | 取 `bool`、`int`、`float`、`string`、`stringSlice`、`duration` 之一。 |
| 默认值标记 | `默认 200` | 命令行自己的默认值。填成一样的值不会产生任何输出。 |
| 控件 | 数字框 / 复选框 / 下拉框 / 文本框 | 有枚举取值的参数变成下拉框；路径类参数带**浏览…**按钮。 |

参数分成 **命令参数**（该命令自己的）和折叠起来的 **通用参数**（从根命令继承的全局参数）两块。
通用参数基本都是噪音，需要时再展开。

有些命令读取 cobra 从不在 `--help` 里声明的裸参数，此时表单会出现**位置参数**区块，值用空格
分隔。GoTree 0.5.2 里受影响的恰好是四个命令：`reroot outgroup`、`collapse clade`、`prune`、
`upload itol`。

## 第三列：工作流、等价命令行、结果

**工作流**按执行顺序列出各步骤，当前选中的步骤带高亮边框。

| 按钮 | 效果 |
|---|---|
| ↑ / ↓ | 调整该步骤顺序。 |
| × | 删除该步骤。 |
| 步骤标签 | 选中该步骤，把它的参数载入第二列。 |
| **运行** | 执行整条链。执行期间按钮禁用。 |
| **清空** | 清空工作流，但保留输入文本和路径。 |

**等价命令行**在你运行之前就实时显示 shell 形式，旁边**复制**写入剪贴板。

**结果**区先按步骤各显示一行——成功是绿色，失败是红色并带上工具自己的消息，外加一个可展开的
原始 stderr——然后显示最终输出：

- 树或统计表按等宽文本渲染。
- SVG 图形渲染成图片。GoTree 只输出 `width`/`height` 而没有 `viewBox`，所以面板会注入一个；
  图片按原始尺寸放在可滚动的框里，因为命令行工具把字号硬编码成 8px，缩小后就看不清标签了。
- PNG（`draw png`）直接解码显示。
- **保存输出…** 会根据结果类型建议 `tree.svg`、`tree.png` 或 `result.txt`。

## 键盘操作

目前没有自定义快捷键。标准操作可用：`Tab` 在控件间移动，在可执行文件框里按 `Enter` 提交新路径；
`Ctrl+F` **不会**聚焦面板的搜索框，请手动点击它。
