# 快速上手

## 需要准备什么

| | |
|---|---|
| 操作系统 | Windows 10 或 Windows 11，64 位 |
| 运行库 | [WebView2 Runtime](https://learn.microsoft.com/zh-cn/microsoft-edge/webview2/) —— Windows 11 自带，多数更新过的 Windows 10 也已内置 |
| 磁盘 | 程序约 30 MB；只有你主动保存时才会写出图形文件 |
| 你的数据 | Newick 树文件（`.tre`、`.nwk`、`.tree`），可选 gzip 压缩 |

就这些。不需要 Python、R、.NET、Node.js 或 Go，也没有安装程序——整个软件就是一个可执行文件。

如果首次启动时 Windows SmartScreen 弹出警告，那是因为 exe 没有做代码签名，选择
**更多信息 → 仍要运行** 即可。

## 五步画出第一棵树

1. **运行 `PhyloPanel.exe`。** 一两秒后，顶栏下方的状态栏会显示类似：

   ```
   GoTree  ·  v0.5.2  ·  82 个可执行命令 / 35 个顶层命令族  ·  命令表来自缓存
   ```

   第一次启动会稍慢一些，因为内置的 GoTree 二进制要解到你的应用数据目录，并且每个命令都要
   被反射一次。整个过程不联网、不下载任何东西。

2. **给它一棵树。** 在**输入**区，二选一：

   - **直接粘贴** —— 选中该单选钮，把 Newick 粘进文本框，例如
     `((A:0.10,B:0.11)85:0.20,(C:0.09,D:0.12)42:0.30,(E:0.05,F:0.07)99:0.18)root;`
     文本会喂给工具的标准输入，因此不会产生任何临时文件。
   - **树文件（传 --input）** —— 输入路径或点**浏览…**选择。当工作流第一步带有输入类参数时，
     面板会自动把你的路径填进 `--input`。远程地址（`http://`）和 `itol://` 也照上游命令行
     支持的样子原样可用。

3. **挑一个命令。** 在左侧**命令表**里点击 `draw svg`，它会出现在**工作流**中，其参数出现在
   **参数**区。

4. **运行。** 点**运行**。状态栏显示 `完成 · 1 步 · 64 ms`，树图出现在**结果**区。

5. **留下结果。** 点**保存输出…**写出 `tree.svg`；或点**等价命令行**旁的**复制**，把这条命令
   带走。

## 怎么读等价命令行

每次运行都会显示产生该结果的确切命令行。它和真正启动进程用的是同一套代码生成的，所以不可能
出现"界面显示一套、实际执行另一套"：

```
reroot midpoint | draw svg --width 900 --height 900
```

两点需要知道：

- 命令里没有可执行文件名；这条命令行的前提是你在一个含有 `gotree` 的终端目录里执行。
- 含有会被 shell 误读的字符的参数会用单引号包住，内部的单引号转义成 `'\''`。原样粘贴到
  `cmd`、PowerShell 或 bash 都能用。

## 东西存在哪里

PhyloPanel 只写下面这些位置，别的地方都不碰。

| 内容 | 位置 |
|---|---|
| 解出的 GoTree 二进制 | `%APPDATA%\app.phylo.panel\tools\gotree-<hash>.exe` |
| 反射出的命令表 | 应用缓存目录，按可执行文件名 + 修改时间各存一份 |
| 语言、主题、上次用的可执行文件、上次的输入路径 | `%LOCALAPPDATA%\app.phylo.panel\` 下的 WebView2 配置目录 |

删掉 tools 目录是安全的，下次启动会重新解出。删掉缓存目录只是让面板重新反射一次。

## 试一个预设

顶栏上有预设工作流按钮。点**中点根化后绘图**，工作流里就会填入两个串联命令，并且参数已经配好。
这是理解"管道"最快的方式：

```
reroot midpoint | draw svg --width 900 --height 900
```

预设是起点而不是限制：之后你可以随意编辑、调序、删除其中任何一步。

## 换一个工具来驱动

左上角的**可执行文件**输入框是可以直接编辑的。输入完整路径，或点**选择…**挑一个基于 cobra 的
命令行程序，比如 `goalign.exe`。面板会重新反射，并变成那个程序的面板。想回到内置二进制，点
**用内置 GoTree**。
