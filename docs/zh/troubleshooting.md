# 故障排查

## 启动与反射

**状态栏显示 `找不到可执行文件：<路径>`。** **可执行文件**框指向的文件已经不存在了——通常是被
删掉的解出工具，或者你手输路径时漏了扩展名。点**用内置 GoTree**即可回到内置二进制。

**状态栏显示 `反射失败`。** 该二进制不是 cobra 程序、文件损坏，或者首次运行时被杀毒软件拦截。
自己在终端里验一下：

```
"C:\path\to\tool.exe" --help
```

能打印命令清单，面板就能反射它；不能，就是工具本身的问题。

**替换过命令行工具，但命令表还是旧的或者空的。** 反射结果按二进制文件名*和修改时间*缓存。如果
你的拷贝工具保留了原始时间戳，缓存看起来就仍然有效。点**重新反射命令表**强制重建。

**第一次启动很慢，之后一直很快。** 正常：内置 GoTree（约 20 MB）只解出一次，每个命令的
`--help` 只读一次，两样结果都会缓存。

## 运行

**`没有可执行的步骤`。** 工作流是空的，先点几个命令。

**`上游进程没有可衔接的输出`。** 某一步本应把 stdout 交给下一进程，但输出流接不上。这通常意味着
前面某步立刻挂掉了——看它上面那行红色的步骤。

**某步在面板里失败，但在终端里能跑通。** 展开该步骤下的**原始 stderr**。两个最常见原因：

- **缺位置参数。** `prune`、`reroot outgroup`、`collapse clade`、`upload itol` 需要裸参数，
  任何参数都替代不了；请填**位置参数**框。
- **某个必填参数被你留成了默认值。** 面板会剔除"只是重复命令行默认值"的参数，这在正常情况下是
  对的，但遇到"该参数必须出现"的命令就不对了。把它改成与默认值不同的值。

**错误信息只是 `Not group given` 之类。** 那是 GoTree 自己的措辞，面板原样透传，不会编造。请去
上游文档里查该命令。

**图是空的或者特别小。** GoTree 把字号硬编码成 8px，并且只输出 `width`/`height` 没有 `viewBox`。
面板会注入 `viewBox`，并把图片按原始尺寸放在可滚动的框里。所以想要更大的树，请调大 `draw svg`
步骤的 `--width` / `--height`，而不是缩放结果区。

**按运行没反应。** 已经有一次运行在进行中——执行期间按钮是禁用的。看状态栏是否显示 `执行中…`。

## 输出

**`写入失败`。** 目标文件被别的程序占用（SVG/PNG 查看器、以及开着 `.txt` 的 Excel 很常见），
或者目标目录只读。关掉查看器再存一次。

**存出来的 SVG 看着正常，但用文本编辑器打开没有 `viewBox`。** 这是对的——面板加的 `viewBox` 只
用于屏显。保存的文件就是 GoTree 自己的输出，逐字节一致。

**PNG 步骤输出的是文本而不是图片。** `draw png` 必须是最后一步，且它的输出要被完整接收；如果
后面还接了步骤，那一步收到的就是二进制垃圾。

## 界面

**界面是中文，我想换英文（或反过来）。** 顶栏 → **语言** → 选择。立即生效并记忆。详见
[语言与主题](language-and-theme.md)。

**深色模式下启动时标题栏先白了一下。** 主题由脚本在文档加载完成后施加，当你显式选择的主题与系统
设置相反时，可能有一瞬闪烁。选**跟随系统**不会闪。

**深色模式下树图还是白底。** 有意为之：GoTree 的 SVG 是黑字透明底，反过来会让树看不见。

**英文界面显得挤。** 英文标签比中文长。窗口不记忆尺寸，把窗口拖宽即可；最小尺寸是 1000 × 660。

## 环境

**提示"此应用无法在你的电脑上运行"或秒退。** 几乎总是老 Windows 10 缺少 WebView2 Runtime。
装微软的 Evergreen 运行时后重试。

**杀毒软件把 exe 隔离了。** 应用首次启动会在自己的应用数据目录里写一个可执行文件，部分杀软会拦。
从隔离区恢复，并为 `%APPDATA%\app.phylo.panel\` 添加排除项。

**不需要联网。** 应用只反射本地二进制，不向任何地方上报。GoTree 自己的 `download`/`upload`
命令会联网，但那只有你主动运行时才会。

## 报问题时要带什么信息

请附上：PhyloPanel 版本、状态栏里的命令行工具及其版本、确切的**等价命令行**、失败步骤的
**原始 stderr**，以及——如果是布局或语言问题——当时用的是哪种语言和哪种主题。
