## 一分钟模型

PhyloPanel 是系统发育学命令行工具的图形驱动器，一共四个环节：

1. **反射。** 启动后它对每个能发现的命令跑一次 `--help`，据此构建命令树和参数表单。界面是
   命令行的一个渲染结果，绝不是命令行的重新实现。
2. **输入。** 树要么以文件路径进来（用 `--input` 传递），要么以粘贴文本进来（写进第一个进程
   的标准输入）。
3. **工作流。** 一个有序命令列表。第 *n* 步的 stdout 由操作系统直接接到第 *n+1* 步的 stdin。
4. **结果。** 最后一步的 stdout，按文本、SVG 图形或 PNG 图片渲染。

界面里的所有其他元素，都服务于这四个环节之一。

## 本文档的排版约定

- `等宽字体` —— 你需要输入的内容，或者界面上原样出现的文字。
- **加粗** —— 你要点击的控件或要填写的输入框。
- "GoTree" 指内置的命令行工具；"面板"指 PhyloPanel 本身。
