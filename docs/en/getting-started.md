# Getting started

## What you need

| | |
|---|---|
| Operating system | Windows 10 or Windows 11, 64-bit |
| Runtime | [WebView2 Runtime](https://learn.microsoft.com/en-us/microsoft-edge/webview2/) — ships with Windows 11, and with most updated Windows 10 installs |
| Disk | ~30 MB for the app; drawings are written only when you save them |
| Your data | Newick trees (`.tre`, `.nwk`, `.tree`), optionally gzip-compressed |

That is the whole list. There is no Python, R, .NET, Node.js or Go requirement, and no
installer — the app is a single executable.

If Windows SmartScreen warns you on first launch, that is because the exe is not code-signed;
choose **More info → Run anyway**.

## Your first tree in five steps

1. **Start `PhyloPanel.exe`.** After a second or two the status line under the header reads
   something like:

   ```
   GoTree  ·  v0.5.2  ·  82 runnable commands / 35 top-level groups  ·  command tree from cache
   ```

   The first launch takes slightly longer because the embedded GoTree binary is unpacked
   into your app-data folder and its command tree is reflected. Nothing is downloaded and
   no network access is involved.

2. **Give it a tree.** Two options, in the **Input** panel:

   - **Paste directly** — select the radio button and paste Newick into the box, e.g.
     `((A:0.10,B:0.11)85:0.20,(C:0.09,D:0.12)42:0.30,(E:0.05,F:0.07)99:0.18)root;`
     The text is fed to the tool's standard input, so no temporary file is created.
   - **Tree file** — type or browse to a path. When the first command accepts an input flag,
     the panel passes your path with `--input` for you. Remote (`http://`) and `itol://`
     references work exactly as the underlying CLI accepts them.

3. **Pick a command.** In the left **Commands** tree, click `draw svg`. The command appears
   in **Workflow** and its parameters appear under **Parameters**.

4. **Run it.** Press **Run**. The status line reports `Done · 1 steps · 64 ms` and the tree
   drawing appears in **Result**.

5. **Keep the result.** Press **Save output…** to write `tree.svg`, or **Copy** next to
   **Equivalent command line** to take the shell command with you.

## Reading the equivalent command line

Every run shows the exact shell line that produced the result. This is generated by the same
code that launches the processes, so it can never drift from what actually ran:

```
reroot midpoint | draw svg --width 900 --height 900
```

Two details worth knowing:

- The executable name is omitted; the line assumes you are already at a terminal in a
  directory that contains `gotree`.
- Arguments that contain characters a shell would misread are single-quoted, with embedded
  quotes escaped as `'\''`. Paste the line into `cmd`, PowerShell or bash as-is.

## Where things are stored

PhyloPanel writes to two folders and nowhere else.

| Content | Location |
|---|---|
| Unpacked GoTree binary | `%APPDATA%\app.phylo.panel\tools\gotree-<hash>.exe` |
| Reflected command tree | the app cache folder, one file per binary name and modification time |
| Language, theme, last executable, last input path | the WebView2 profile under `%LOCALAPPDATA%\app.phylo.panel\` |

Deleting the tools folder is safe — it is recreated on the next launch. Deleting the cache
folder only forces a re-reflection.

## Try a preset

The header carries preset workflows. Press **Mid-point reroot then draw** and the workflow
fills with two chained commands, already populated with sensible flags. This is the fastest
way to see what a pipeline looks like:

```
reroot midpoint | draw svg --width 900 --height 900
```

Presets are a starting point, not a locked mode: edit, reorder or remove any step afterwards.

## Pointing at a different tool

The **Executable** field at the top left is editable. Type a full path, or press **Browse…**
and pick any cobra-based CLI — `goalign.exe`, for instance. The panel re-reflects and becomes
a panel for that tool: every command and flag appears, and pipelines work. Only GoTree is
embedded in the download, and only GoTree has preset workflows today — see
[Command coverage](command-reference.md) for what a tool without a pack does and does not get.
Press **Use bundled GoTree** to jump back to the embedded binary.
